# DoubleTake Memes 💬

Comic style double meaning meme generator!

## Features
- **Auto Generate**: Instantly create fun double-meaning (punny) memes with comic style backgrounds.
- **Upload Your Picture**: Upload any image and overlay hilarious double-entendre captions.
- **Comic UI**: Bold fonts (Bangers, Comic Neue), thick borders, yellow comic paper vibe, speech-bubble logo.
- **Export**: Download your meme as PNG with a beautiful small watermark logo in the corner: "Generated by DoubleTake".
- Fully client-side, no backend needed. Works offline after load.

## How to Use
1. Click **Auto Generate Fun Meme** for random comic memes.
2. Or click **Upload Your Picture** to use your own photo.
3. Edit the caption if you want, or regenerate.
4. Hit **Export Meme** to download with watermark.
